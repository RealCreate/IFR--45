# IFR ±45 Trainer

Quick mental-maths drill for heading ± offsets (useful for procedure turns, intercepts and holding entries).

- A random heading 001–360 appears with an offset like **+45** or **−33**; type the 3-digit answer (e.g. `045`) and it checks automatically.
- **Offset** (in Settings): the classic ±45, a **custom** number (1–180°), or **random** irregular offsets every question (up to 90° or 180°, any degree or steps of 5°/10°).
- **Direction**: Mixed, add only, or subtract only. Free practice or a 60-second sprint, with a best score kept per mode.
- Compass rose turns to each heading and shows the target bug after you answer.
- `000` and `360` both count as north. Keep typing after a miss to skip the pause. Works with the on-screen keypad or a keyboard (`S` opens settings).
