# IFR ±45 Trainer

Quick mental-maths drill for heading ±45° (useful for procedure turns, intercepts and holding entries).

- A random heading 001–360 appears with **+45** or **−45**; type the 3-digit answer (e.g. `045`) and it checks automatically.
- Modes: Mixed / +45 only / −45 only, Free practice or a 60-second sprint.
- `000` and `360` both count as north. Works with the on-screen keypad or a keyboard.

Live: https://realcreate.github.io/IFR--45/
